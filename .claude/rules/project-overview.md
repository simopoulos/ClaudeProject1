## Project

Single-file static website: `nexa.html` — a light-themed dental clinic homepage for **Art of Smile Dentistry** (Yonge & Eglinton, Toronto). No build tools, no framework, no dependencies beyond Google Fonts. Open directly in a browser.

## Page layout (top → bottom)

Nav → Hero → Services → Why Us (charts + about photo) → Team → Testimonials → Philosophy & Contact → Footer Stats → Footer Nav
