This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Rules are split into `.claude/rules/`:
- `project-overview.md` — what the project is, file structure, page layout, JS behavior map
- `clinic-content.md` — real clinic data, doctors, services, and image URLs
- `design-system.md` — colors, fonts, spacing tokens, component patterns
- `git-workflow.md` — commit and push instructions
